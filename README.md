# Rock, Paper, Scissors, Stock!

Python command-line programs for Rock Paper Scissors and historical stock prices.

```bash
python -m pip install -r requirements.txt
python -m app.rps
python -m app.stocks
python -m pytest
```

Set `ALPHAVANTAGE_API_KEY` for daily stock data. The bundled historical examples use [Vega Datasets](https://vega.github.io/vega-datasets/datasets/stocks/).
